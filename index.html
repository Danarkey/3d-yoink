LOCAL MODEL CONVERTER

3D Yoink

Grab 3D models as GLB files from Meshy and Tripo Studio.

Meshy

Paste a public Meshy post link. Downloads the cover model as a GLB with embedded textures.

Model licences still apply.

Tripo Studio

Grab any public Tripo model as a GLB. Uses a bookmarklet because Tripo's site blocks automated fetches.

Setup (once)
  1. Drag this to your bookmarks bar: Yoink GLB
Usage
  1. Visit any Tripo Studio model page
  2. Click Yoink GLB in your bookmarks bar
  3. The model downloads as a GLB automatically

GLB models download directly. FBX models (rigged) are converted via Blender with textures.
